# 今日の美紅はここにいるよ

HTML・CSS・JavaScriptだけで動作する、日本国内向けのGPS表示アプリです。

## 🌸 表示

- 背景 `#FF8C73`、白文字、全て **Mochiy Pop One（400）** です。
- 左上に `#今日の美紅はここにいるよ`、中央に緯度・経度をDMS形式で2行、下に都道府県・市区町村名を1行表示します。
- 画面内に収まる最大の16:9領域を中央に配置します。縦長画面では幅、横長画面では高さに合わせて縮小します。
- 政令指定都市は市まで、東京都の特別区は区まで表示します。町村は実際の町村名を表示します。
- 取得中やエラーは地域名の欄に表示します。GPS取得に失敗した場合は古い座標を消します。

## 🚀 起動

Node.jsとPython 3が利用できる環境で、次を実行します。依存パッケージのインストールは不要です。

```sh
npm start
```

[http://localhost:5173](http://localhost:5173)を開き、ブラウザの位置情報の利用を許可してください。
Pythonだけでも `python3 -m http.server 5173 --bind 127.0.0.1` で起動できます。

公開する場合は、このフォルダーのファイルを **HTTPSの静的ホスティング** に配置してください。
GPS・PWAにはHTTPS、またはlocalhostが必要です。`index.html`を直接開く `file://` では動作しません。
スマートフォンからアクセスする場合もHTTPSが必要です。

## 📱 PWA・全画面表示

- 対応ブラウザの「インストール」または「ホーム画面に追加」でPWAとして利用できます。iOSではSafariの共有メニューから追加します。
- 画面のダブルクリック、または **Fキー** で全画面を切り替えます。終了はEscキーでも可能です。
- 全画面APIに対応していない端末では、ホーム画面からPWAとして起動してください。
- 初回の読み込みとService Workerのインストールが完了すると、フォント・全国地域データを含めてオフラインで起動できます。初回は約30MBのローカル資産を読み込みます。
- 地域データはWeb Workerで処理し、画面の操作を妨げないようにしています。

## 🔒 外部通信・位置情報

Google Fontsのフォントファイルも同梱しています。外部のフォント配信、住所検索API、地図サービス、解析ツールは利用しません。
アプリは同じ配信元のファイルだけを読み込み、**緯度経度を送信・保存しません**。住所の判定は端末内で行います。
Content Security Policyで外部ドメインへの接続も制限しています。

ブラウザのGeolocation APIを高精度モードで利用します。ブラウザ・OSはGPSに加えてWi-Fi等で測位する場合があり、OS側の通信や測位方法はこのアプリでは制御できません。
オフライン測位が可能かどうかは端末のGPS機能に依存します。

## 🗾 行政区域データ

国土交通省「[国土数値情報・行政区域データ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03.html)」を加工した
[Geolonia japanese-admins](https://github.com/geolonia/japanese-admins)の **2022年1月1日時点** の全国データを同梱しています。
約5m程度の許容幅で形状を簡略化し、整数マイクロ度のバイナリに変換しています。離島、複数の領域、飛び地、穴を保持します。

境界付近ではGPSの誤差や簡略化の影響があり、2022年以降の行政区域の変更は反映されていません。
海上・国外・データの対象外では、座標は表示し、地域名は「市区町村を特定できません」と表示します。

`assets/data/LICENSE-geolonia.txt`にGeoloniaのMITライセンスを収録しています。
元の行政区域データの出典・加工内容は `assets/data/SOURCES.md` に記載しています。
フォントの[SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/mochiypopone/OFL.txt)は `assets/fonts/OFL.txt` に収録しています。

データを再生成する場合はGeoloniaのソースアーカイブを取得し、ShapelyがインストールされたPython環境で実行します。
アプリの利用にはPythonやShapelyは不要です。

```sh
python3 scripts/build-areas.py /path/to/japanese-admins.tar.gz
```

アプリやデータを更新する場合は、`sw.js`の `CACHE` のバージョンも変更してください。
